# Driver contract

Status: proposed v1; no external driver process protocol is implemented. Drivers are trusted executable code, not sandboxes. Human enrollment is out-of-band; neither model, driver nor target can enroll itself. `observe` is mandatory and read-only; unsupported observation is not allowed. Approval-required policy may permit read-only observation/planning, never apply.

## Enrollment and identity

Human reviewer distributes a revisioned enrollment bundle with reviewed artifact through an independently controlled authenticated channel. Exact closed enrollment object and field shapes, sorting and digest are in schemas.md. It binds driver/protocol, executable/dependency SHA-256 digests, provenance/interpreter, configuration digest, resource kinds, exact schema IDs/digests/documents, capabilities, OS identity, separate principal, targets, effects, sinks and hard limits. Trust is that channel or separately established signature trust root; no signature format/trust-root discovery defined. Clients validate locally and never fetch schemas/code or resolve foreign references. Schema ID names an immutable document within enrollment, not a resource. `driver_list` discovery returns exactly `driver_id,protocol,kinds,capabilities,limits`; it reveals no schema IDs, digests, or documents. The human supplies allowed schema IDs; the keeper validates each against enrolled Kind and SchemaEntry. Verify executable, dependencies, configuration and exact enrolled OS identity before each process. Execute directly, never via PATH lookup, shell, hooks, writable code/config, dynamic loading or undeclared dependencies.

## JSON Schema subset

Only Draft 2020-12 (`https://json-schema.org/draft/2020-12/schema`). Schemas are duplicate-free UTF-8 JSON objects, depth ≤16, ≤4096 nodes, ≤65536 canonical bytes. Reject unknown keywords/vocabularies, wrong `$schema`, booleans, references, formats, regex/pattern, numbers/floats, composition/conditional keywords. Allowed keywords: `$schema`, `type`, `enum`, `const`, `title`, `description`, `default`, `examples`, `properties`, `required`, `additionalProperties`, `items`, `minItems`, `maxItems`, `uniqueItems`, `minProperties`, `maxProperties`, `minLength`, `maxLength`, `minimum`, `maximum`, `exclusiveMinimum`, `exclusiveMaximum`, `multipleOf`. Types: object/array/string/integer/boolean/null; arrays of types only express explicit nullability. Objects require `additionalProperties:false`, every property required. Strings maxLength 1..4096; arrays maxItems 0..256; objects maxProperties 0..128. Applicable min bounds are nonnegative and ≤ maximum. Integers/bounds within ±(2^53−1); multipleOf positive integer. Enum 1..256 distinct values; required names distinct and declared. `items` applies one schema; const/enum values obey same limits. No text is thereby proven nonsecret.

## Canonical content and digest

Canonical JSON is `JCS-SSJACK-1`, not RFC 8785. Reject duplicate keys, non-NFC strings, floats/nonfinite numbers, invalid UTF-8, trailing bytes, controls and lone surrogates; integers only. SHA-256 domains: `ssjack-schema-v1\0` for schema documents, `ssjack-tool-schema-v1\0` for descriptor input/output pairs, `ssjack-plan-v1\0`, `ssjack-enrollment-v1\0`, `ssjack-desired-v1\0`, `ssjack-effects-v1\0`; append canonical bytes, lowercase hex. Digest binds content, not provenance or authorization.

## Process and frames

Each action is a fresh executable directly, never shell, under exact enrolled OS identity and private working directory. Environment is fixed empty in v1; never inherit ambient variables. Verify the exact enrolled actual OS identity (not a caller-supplied label) before each process. OS identity and network enforcement are external trusted policy/backend responsibilities; enrollment declarations alone do not enforce them. Execute directly, never via PATH lookup, shell, hooks, writable code/config, dynamic loading or undeclared dependencies.

Driver subprocess protocol is JSON, not Ktav: exactly one request and response frame, each four-byte unsigned big-endian payload length plus UTF-8 JSON. Payload 1..65536 bytes excluding prefix; complete frame ≤65540. Reject overflow before allocation, truncation, extra frames/bytes, stdout noise, duplicate keys, unknown fields, invalid UTF-8/JSON, schema violations and correlation mismatch. Nonzero exit is never semantic success. Broker Ktav frame is separately capped at 262144 payload bytes.

`internal/driverframe` is a disconnected, reusable transport prerequisite only; no runtime path invokes it, and it does not implement this contract's JSON, UTF-8, duplicate-key, schema, correlation, stdout, or process-exit checks. It bounds the declared payload before allocation; `Read` consumes exactly one frame and `RequireEOF` detects trailing bytes (including a duplicate frame). Calls may block on a live generic reader/writer; callers must close the producer when EOF is required and enforce deadlines/cancellation through the transport or surrounding orchestration. Repeated `(0,nil)` reads/writes fail with `ErrNoProgress`; invalid read/write counts fail rather than being trusted. Incomplete frames preserve the underlying non-EOF I/O error; EOF before any header bytes returns `io.EOF`; EOF after a partial header or anywhere before the declared payload is complete returns `io.ErrUnexpectedEOF`. A reader may return all requested bytes together with EOF: the section is complete, and EOF applies only to subsequent frame data. Invalid lengths return `ErrLength`, trailing bytes `ErrTrailing`. Driver execution remains unimplemented; this package does not expose a CLI or MCP operation.

All request fields required: `{protocol:I,request_id:S,action:S,target:S,kind:S,schema_id:S,resource_id:S,desired:O|null,expected_revision:S|null,plan_digest:S|null,allowed_effects:A<RuntimeEffect>,deadline_unix_ms:I,max_response_bytes:I,operation_id:S|null}`. Request ID is fresh 16-byte unpadded base64url, supplied through stdin in the framed request; operation ID is null for observe/plan, required and keeper-stable for apply/cancel/reconcile. Protocol IDs are carried in the stdin request, not argv or environment. Deadline is UTC Unix milliseconds; max response 1..65536. Desired ≤32768 canonical bytes; projection ≤8192.

Actions:
- `observe`: desired, plan digest, revision, operation ID null; effects empty. Returns `{state:S,revision:S|null,projection:O}`.
- `plan`: desired required; expected revision is observed revision; digest/operation ID null; effects empty. Read-only; returns `{effects:A<RuntimeEffect>,precondition:S|null}`.
- `apply`: desired exactly keeper-stored; digest non-null; effects exact approved records; expected revision equals plan precondition; operation ID required/stable. Sole mutating action; returns `{state:S,applied_revision:S|null,verified:B,projection:O}`. Empty effects complete durably only after fresh observe confirms exact desired state and precondition; never invoke apply or fabricate revision.
- `cancel`: operation ID and plan digest required; desired/revision null; effects empty. The original operation's cancellation reserves its sole cancel action; at most one apply and that apply's one cancel may run in parallel. Queue deadline is exactly first acceptance time + 10000 ms; execution deadline is the earlier of actual launch + 600000 ms and the original operation's absolute deadline. Retries do not extend either deadline. Queue expiry remains `pending` and must not auto-launch later. Return `unsupported` only when cancel capability is absent; local stop is not proof of cancellation. Returns `{cancellation:confirmed|unsupported|pending}`.
- `reconcile`: operation ID and plan digest required; desired/revision null; effects empty; read-only. Returns `{state:S,applied_revision:S|null,delivered_revision:S|null,observed_revision:S|null,adopted_revision:S|null,verified:B,projection:O}`.

`observe` is mandatory. Every action data field named `state` is exactly `present|absent|unknown`, never free-form text. Approval-required permits observe/plan but not executable apply.

## Safe output

Response DTO exactly `{protocol:I,request_id:S,outcome:S,error_code:S|null,data:O|null}`. `ok` has action-shaped data and null error. Fixed errors: `conflict/PRECONDITION_FAILED`, `unsupported/POLICY_DENIED`, `no_effect_failure/BACKEND_FAILED`, `unknown/OUTCOME_UNKNOWN`, each null data. No free-form error text or extra fields. Keeper validates schema, byte caps, correlation, action/outcome. Proven pre-invocation failure means no invocation/effect; after invocation may begin report unknown until evidence resolves it.

Only human-reviewed typed schema-validated safe fields and enrolled effect summaries may be projected. Unknown/free-form output fails closed; reject, never truncate or partially expose. Never return paths, endpoints, environment, process output, credentials, secret material or unapproved text. Adoption requires enrolled verify_adoption evidence. Secret delivery/adoption and SecretRef absent. One-use attachment cannot reconnect; quarantine requires human inspection and fresh session. Capabilities are sorted subset `observe,plan,apply,conditional_write,exclusive_owner,cancel,reconcile,verify_adoption`; observe mandatory. Unknown capabilities reject enrollment. Capabilities never exceed enrolled target/effects/sinks/principal/backend permissions.
