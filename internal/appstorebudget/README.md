# Fixed application-store operation admission

This cooperative process-local guard has exactly two fixed slots and admits at most one operation for each nonzero store ID. `TryAcquire` never waits; invalid IDs or occupied/global-full admission return no lease. Successful calls return idempotent release closures. Old or concurrent double release cannot free a later owner's slot. Only two public random IDs are retained, never secrets, keys, payloads or a growing store registry.

Public application-store `Derive` and `CheckSnapshot` own a lease around their complete primitive call, before KDF/Reader work. Busy fails closed. The shared expensive KDF guard remains a separate one-batch constraint across SSH/app-store password derivation. Private test/layer helpers are not standalone store-operation APIs. A future composite transaction controller must own the correct complete transaction/lock lifetime and avoid nesting another lease around an entrypoint that already owns one; this guard is not a completed transaction manager.

A lease is released only on actual return, not merely when cancellation is signalled. Active Argon work or a blocked Reader must not continue under a supposedly freed slot. Callers must provide independently bounded/cancellable I/O; no hard wall-clock, fairness, OS/cross-process exclusion, source identity, authorization or host-wide RSS cap is established. Separate processes or code bypassing admission are not controlled. The required filesystem/service writer serialization and authenticated nonce/commit protocol remain separate.

Tests hold concurrent owners until all attempts finish, proving two admissions without timing-based absence checks. They cover same-store denial, exhaustion, late/concurrent release and post-error reuse. Crypto integration uses a private fake derivation callback to prove denial before KDF, and the existing full-cost CI master test probes public CheckSnapshot before Reader.Read and verifies release after return. Local work ran formatting only; public GitHub CI supplies execution evidence. Crypto formats/profiles, four independent 1-GiB Argon2id passes and 1000 AES layers are unchanged.
